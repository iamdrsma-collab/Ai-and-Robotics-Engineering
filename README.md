## Production Overview

- **Video Format:** 1280×720 HD (16:9, 720p), presentation-style university lecture series
- **Audio & Voice:** Mono studio-quality narration with interactive pre-generation voice audition and consistent per-course voice preservation
- **Course Depth:** Minimum **100,000+ spoken words per course**, structured into sequential modules, lessons, practical demonstrations, laboratories, tutorials, revision sessions, and assessments
- **Pipeline Architecture:**
  `Course selection → Voice audition → User selects voice → Course syllabus generated → 100k+ narration generated in modules → Slides/diagrams/images generated → Practical demonstrations → TTS → Mono audio → 720p video rendering → Module-by-module output → Complete course playlist`
